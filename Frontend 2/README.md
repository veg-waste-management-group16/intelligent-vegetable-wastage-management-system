# Payment Frontend (React)

This frontend is migrated to React + Vite.

## Stack

- React
- React Router
- Vite

## API Base URL

The app calls:

`http://localhost:8080/api/payments`

## Routes

- `/#/customer-dashboard` - customer cards and payment entry
- `/#/payment` - payment form
- `/#/success` - payment success and receipt
- `/#/admin` - admin overview, filters, requests, report

## Run locally

1. Install dependencies:

	`npm install`

2. Start dev server:

	`npm run dev`

3. Open the URL printed by Vite (usually `http://localhost:5173`).
